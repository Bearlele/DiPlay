# DiPlay

为兼容的比亚迪安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

> 这些项目专注于比亚迪汽车。它们可能在其他品牌上运行，但其他品牌不在支持范围内，也没有增加支持或修复其品牌特定兼容性问题的计划。

[下载与中文网站](https://shihabal3amri.github.io/DiPlay/zh-Hans/) · [完整说明](README.md) · [报告问题](https://github.com/shihabal3amri/DiPlay/issues/new/choose)

0.2.8 为公开预览版，未经 Apple 认证。请安装在车机上，而非 iPhone。无需越狱、转接盒、账号或认证服务器。Android 8.0（API 26）及以上兼容移植属于实验版本，须在目标车机上验证；无线连接可选车机已有热点或旧版 Wi-Fi Direct。若车机只提供 2.4 GHz，就在车机系统中使用该频段；DiPlay 只保存热点名称和密码，并自动处理信道。用户已在 Android 8.0 小米 6 真机上确认无线 CarPlay 画面和声音正常。车机实测及有线连接仍需验证。

本版本改进了无线 CarPlay 从蓝牙切换到 Wi-Fi 时以及 USB 连接下的位置上报，更新频率限制为每秒最多一次。可选的 ADB 车轮速度功能会在没有 GPS 时向 iPhone 发送比亚迪车轮速度和挡位，以支持位置推算；隧道效果尚未验证。新增可选的 iOS 27 驻车视频功能，可在车辆处于 P 挡时于车机屏幕播放受支持的视频，并使用 iPhone、触屏和方向盘控制。离开 P 挡后播放器会关闭。Apple TV+ 等受 DRM 保护的视频暂不支持，因为 DiPlay 不是获得 FairPlay 授权的接收器。

认证使用从公开固件中提取的实验性配件身份，无法保证未来持续可用。部分车机仍可能卡顿或无法应用图标大小设置。应用界面支持英语、简体中文、阿拉伯语、俄语和西班牙语。源代码、构建说明及许可证随版本提供。

## 本分支 Android 8 兼容改动（尚未发布）

以下修改属于当前源码分支，不包含在已发布的 0.2.8 APK 中：

- 将应用最低 Android 版本调整为 Android 8.0（API 26），并保留旧版 Wi-Fi Direct 连接路径。实际 Wi-Fi 频段由车机固件和驱动决定。
- 已在 Android 8.0 小米 6 真机确认无线 CarPlay 画面和声音正常；Android 8.1 目标车机及有线 CarPlay 尚待验证。
- 音乐缓冲新增 0 毫秒选项，并保留 300、500、1000 毫秒。0 毫秒会在收到第一段解码音频后开始播放，不增加预缓存；解码和硬件仍有固有延迟，网络不稳时可能卡顿。
- 新增关闭车机触屏事件转发的设置。关闭后仍可接收 CarPlay 画面和声音。
- 屏幕尺寸变化触发重连时，会等待旧无线连接栈关闭并释放 Wi-Fi Direct 组。
